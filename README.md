# バス運行状況確認システム (Bus-Location-Checker) - v1.0 製品版

このシステムは、幼稚園や保育園、学校などのバス運行状況をリアルタイムで保護者に共有するためのツール群です。

## 🌟 アップデート情報

### v1.0 製品版完成 : OK
- **初回登録・Google 連携フロー**: 利用情報を入力した後、Google アカウントで認証する「入力後ログイン」方式を採用。
- **マルチバス・兄弟対応**: 一つのアカウントに複数のバスを紐付け（別のバスを登録）、画面上部で簡単に切り替え可能に。
- **道路沿いの精緻なルート描画**: OSRM エンジンを利用し、地図上の道路を正確になぞるルートを表示。
- **10m 接近判定ロジック**: バス停の半径 10m 以内への進入で「到着」、脱出で「通過」と判定する厳格なロジックを実装。
- **リアルタイム時速・位置更新**: WebRTC P2P 通信により、遅延のない滑らかな位置・速度（km/h）表示を実現。
- **管理者機能のフルセット**: 停留所へのクイックジャンプ、路線の完全削除、全登録データに基づく動的な年度フィルタリング。
- **セキュリティの強化**: 管理者ポータルをパスコードで保護し、SHA-256 ハッシュ照合を採用。

### alpha3.0 アップデート : OK
- **UI の徹底的な簡素化**: モバイル端末での片手操作と視認性を極限まで追求。
- **個別・一斉メッセージ配信**: バスごとの緊急テロップ配信と、全車共通メッセージの出し分けが可能。

## 📖 詳細仕様とロジック

### バスの状態表示（時間外 / 停止中）
1. **通信断絶判定**: バス側からの位置信号が **5分以上** 途絶えると「時間外 / 停止中」の赤いバッジが表示されます。
2. **ルート描画の減衰**: 通信断絶時はルートの線が薄くなり、情報の鮮度が低いことを示します。

### 10m 接近・通過判定の仕組み
- **進入 (Arrived)**: バスがバス停の座標から半径 **10m 以内** に入った瞬間に「到着」と判定し、マーカーの色を更新します。
- **脱出 (Passed)**: 到着判定後、バスが再び半径 **10m の外側** に出た瞬間に「通過済み」となり、ルートの線とマーカーがグレーアウトします。
- **補完ロジック**: GPS の瞬き等で 10m 判定を逃した場合でも、OSRM の詳細ルート上のインデックスを監視し、バス停を一定以上通り過ぎた場合に自動的に「通過済み」に切り替えます。

### ユーザー削除システム (GAS)
管理者がユーザーを削除すると、Google Apps Script (GAS) 経由で `Firebase Auth` からのアカウント物理削除が実行されます。
※ GAS の Web App URL は管理者画面の `GAS_WEB_APP_URL` に設定する必要があります。

#### GAS セットアップ手順:
1. Google Apps Script エディタを開き、`gas/user-management.gs` の内容を貼り付けます（※ライブラリ追加は不要です）。
2. GCP コンソールでサービスアカウントを作成し、`Firebase Authentication 管理者` のロールを付与します。
4. JSON キーを作成し、そのメールアドレスと秘密鍵をスクリプト内の `CLIENT_EMAIL` と `PRIVATE_KEY` に記入します。
 5. スクリプト内の `ALLOWED_DOMAIN` に、管理者ページを公開するドメイン（例: `https://your-name.github.io`）を設定します。
 6. 「デプロイ > 新しいデプロイ」を選択し、種類を「ウェブアプリ」、アクセスできるユーザーを「全員」にしてデプロイします。
6. 発行された URL を `web/admin/index.html` の `GAS_WEB_APP_URL` に設定します。
