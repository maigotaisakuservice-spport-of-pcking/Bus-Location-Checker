# バス運行状況確認システム (Bus-Location-Checker) - v1.0 製品版

このシステムは、幼稚園や保育園、学校などのバス運行状況をリアルタイムで保護者に共有するためのツール群です。

## 🌟 アップデート情報

### v1.0 製品版完成 : OK
- **Google ログイン連携**: 保護者アカウントを Google アカウントと紐付け。次回以降のログインがスムーズに。
- **マルチバス対応**: 兄弟などで複数のバス路線を登録・切り替え可能。
- **道路沿いのルート描画**: OSRM を使用し、直線ではなく実際の道路に沿った正確なルートを表示。
- **10m 判定ロジック**: バス停の前後 10m 以内への進入・脱出で「到着/通過」を正確に判定。
- **リアルタイム時速表示**: WebRTC P2P 通信により、遅延のない滑らかな位置更新と時速表示を実現。
- **管理者機能の強化**: 停留所リストからの地図ジャンプ、バス路線の完全削除、動的な年度フィルタリングを実装。
- **セキュリティ強化**: 管理者ポータルのパスコード保護と Firestore での「自分のバス停」永続化。

### alpha3.0 アップデート : OK
- **UI の大幅な簡素化**: モバイルでの視認性と操作性を優先したデザインに刷新。
- **緊急テロップの個別配信**: 全路線一括、または特定のバス路線を指定した緊急メッセージ配信に対応。
- **「自分のバス停」推定機能**: 登録したバス停までの距離と到着予測時間をリアルタイム算出。

## 📁 ディレクトリ構造と役割

- **`web/`**: ブラウザで動作する軽量なアプリケーション群。
  - **`user/`**: 保護者用。Google ログインで「自分のバス停」や登録路線を保存。
  - **`admin/`**: 管理者用。路線の設定、ユーザー削除、緊急連絡の管理。
  - **`sender/`**: 運転手用（Web版）。ブラウザベースで位置送信が可能。
- **`mobile/` (Cordova)**: 運転手専用のネイティブアプリ。バックグラウンドでの安定した GPS 送信に必須。
- **`gas/`**: Google Apps Script。Firebase Auth のユーザー削除など、バックエンドの補助処理を担当。

## 🔒 セキュリティと認証

### 管理者ポータル
- **アクセス**: ルートの `index.html` からアクセス。
- **パスコード**: `admin-dev-7x9q` (開発用デフォルト)
  - ※ `index.html` 内では SHA-256 ハッシュ化して照合しているため、ソースコードから直接漏洩しません。

### ユーザー認証
- **Google 連携**: 初回登録時に Google アカウントと連携することで、招待コードの再入力なしでログイン状態を維持。
- **暗号化 (E2EE)**: バス停名や現在地は AES-256 でクライアント側で暗号化。Firebase 側でも内容は閲覧できません。

## 📖 詳細仕様とロジック

### バスの状態表示（時間外 / 停止中）
保護者画面で「時間外 / 停止中」と表示される条件は以下の通りです：
1. **通信途絶**: バス側からの位置更新が **5分間** 途絶えた場合。
2. **手動停止**: ドライバーがアプリで「送信停止」を押した場合。
3. **強制停止**: 管理者がダッシュボードでそのバスを「停止中」に設定した場合。

### ルートとバス停の判定
- **到着判定**: バスの現在地がバス停の座標から **半径 10m 以内** に入った瞬間に「到着」とみなします。
- **通過判定**: 到着判定後、再びバスがバス停から **10m 以上** 離れた場合に「通過済み（グレー）」にマーカーとルートの色が切り替わります。
- **作画**: バス停間を OSRM API で補完し、実際の走行ルートに合わせた線を引きます。

### ユーザー削除システム (GAS)
管理者がユーザーを削除すると、以下のフローが実行されます：
1. 管理者画面から Google Apps Script (GAS) の Web API を呼び出し。
2. GAS が Firebase Admin SDK 特権を使用して、Firebase Auth からユーザーアカウントを物理削除。
3. 同時に Firestore 上のユーザー関連ドキュメント（`users`, `users_meta`）を削除。
これにより、不要なデータと認証情報を完全にクリーンアップします。

## ⚙️ 導入・設定ガイド

1. **Firebase 設定**: `web/shared/utils.js` に自身の Firebase API キーを記入。
2. **FCM VAPID キー**: `web/user/index.html` の `getToken` 部分に Firebase コンソールから取得したキーを記入。
3. **GAS 連携**: `gas/user-management.gs` を Google Apps Script にデプロイし、その URL を `web/admin/index.html` の `GAS_WEB_APP_URL` に記入。
