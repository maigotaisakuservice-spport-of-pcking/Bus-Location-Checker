# バス運行状況確認システム (Bus-Location-Checker)

このシステムは、幼稚園や保育園、学校などのバス運行状況をリアルタイムで保護者に共有するためのツール群です。

## 📁 ディレクトリ構造の理由

本プロジェクトは `mobile` と `web` の2つの主要ディレクトリに分かれています。

- **`web/`**: ブラウザで動作する軽量なアプリケーション群です。
  - **`user/`**: 保護者用。インストール不要で、スマホのブラウザからすぐにバスの位置を確認できます。
  - **`admin/`**: 園・学校の管理者用。路線の設定やユーザー管理を行います。
  - **`sender/`**: 運転手用（Web版）。ブラウザベースで位置送信が可能ですが、バックグラウンド動作には制限があります。
- **`mobile/` (Cordova)**: 運転手専用のネイティブアプリです。
  - **なぜ必要なのか？**: スマホのブラウザはセキュリティ上、画面を閉じるとGPSの取得を止めてしまいます。Cordovaを使用することで「バックグラウンド・モード」を有効にし、**スマホをポケットに入れた状態でも位置情報を送り続ける**ことができます。

---

## ⚙️ 設定ファイルの役割

- **`firebase.json`**: Firebaseの構成ファイルです。
  - どのファイルをWeb公開（Hosting）するか、どのセキュリティルールを適用するかを定義しており、**デプロイに必須**です。
- **`firestore.indexes.json`**: データベースの「索引」設定です。
  - 「特定のバスのバス停を名前順で取得する」といった複雑な検索を高速に行うために必要で、これがないとデータベースエラーが発生する場合があります。

## 📖 操作マニュアル

### 1. ユーザー用画面（保護者向け）
ブラウザでアクセスし、配布された招待コードでログインします。

- **バスの確認**: 地図上に赤いアイコンでバスが表示されます。
- **「自分のバス停」とは？**:
  - 自分の子供が乗り降りするバス停を地図上で選び、「ここを自分のバス停にする」ボタンを押すと設定されます。
  - 設定すると、**バスから自分のバス停までの距離と到着予測時間（あと何分か）**が画面上に表示されるようになります。
- **登録と変更**:
  - 保護者が自分自身の端末で自由に設定できます。
  - 別のバス停をタップして再設定すれば、いつでも変更可能です。
- **自動追尾**: 画面右下の「指紋アイコン」が赤い時は、バスが動くのに合わせて地図が自動でスクロールします。

### 2. 管理者用パネル
園のPCなどからアクセスし、Googleアカウントでログインします。

- **ダッシュボード**: 運行中のバス台数を確認したり、全保護者へ「雪のため遅延」などの**緊急テロップ**を配信できます。
- **ユーザー管理**: 登録された保護者の一覧を確認できます。年度末には「2024年度」のユーザーを一括削除して整理できます。
- **バス停・ルート編集**: 地図上をクリックするだけでバス停を追加できます。追加した順番にルートが自動で結ばれます。

### 3. 送信用アプリ（運転手向け）
`mobile`フォルダ内のアプリ、または `web/sender` を使用します。

- **ログイン**: 管理者から発行された招待コードを入力します。
- **送信開始**: 大きな「送信開始」ボタンを押すと、位置情報の共有が始まります。
- **注意点**: 運行が終わったら必ず「停止」ボタンを押して終了してください。

## 🔒 セキュリティとプライバシー

- **エンドツーエンド暗号化 (E2EE)**: バス停の名前や現在地などは、すべて暗号化されて保存されます。システム管理者（Firebase）であっても、鍵を持っていない限り内容を覗き見ることはできません。
- **匿名認証**: 保護者は個人情報を登録せずに利用できる仕組みを採用しています。

## 🧪 テストの実行

プロジェクトの品質を維持するために、Playwrightを使用したスモークテストを導入しています。

```bash
# 依存関係のインストール
npm install

# テストの実行
npx playwright test
```

このテストは、GitHub Actionsによってビルド時に自動的に実行されます。
